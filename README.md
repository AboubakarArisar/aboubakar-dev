# aboubakarisar.tech

Personal portfolio of Abou Bakar Arisar, full-stack software engineer. React, TypeScript and Vite, deployed on Vercel.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
npm run lint
```

- Projects: `src/data/projects.ts` (screenshots in `public/work/<slug>-{800,1600}.webp`)
- Links and contact details: `src/data/site.ts`
- Experience: `src/components/Experience.tsx`
- Brand assets: `public/brand/`, favicons in `public/`
